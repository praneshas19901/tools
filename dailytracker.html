Deploying to GitHub Pages

Host this Daily Tracker app for free on GitHub Pages in under 2 minutes.

1 Save the File

Save the code of this page as index.html on your computer.

2 Create a GitHub Repository

Go to GitHub, log in, and create a new repository (e.g., named daily-tracker). Set it to Public.

3 Upload index.html

Click on "uploading an existing file" inside your repository, drag and drop your index.html file, and click Commit changes.

4 Enable GitHub Pages

Go to your repository's Settings tab -> Click on Pages in the left sidebar -> Under Build and deployment, select Source as Deploy from a branch and Branch as main (or master) and root folder / (root). Click Save.

You're Done!

Within 60 seconds, GitHub will provide your live URL (e.g. https://yourusername.github.io/daily-tracker/) where your app is fully operational with persistent local storage.
