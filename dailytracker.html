App Usage & File Access Guide

Everything you need to know about setting up and using Elite Tracker

1. How to Use the App

The Elite Daily Tracker helps you manage daily routines, habit execution, and track daily goals:

  • Date Navigation: Pick any date using the calendar control to view or retroactively complete tasks.
  • Task Checklist: Check off activities as you complete them throughout your day. Progress automatically calculates metrics and pillars.
  • History & Missed Tasks: Open the "History & Missed" tab to analyze past dates, view overall completion percentages, and list uncompleted tasks.

2. Folder Connection & Required JSON Files

To connect your local data directory, click "Connect Data Folder" in the top header and select a local directory on your machine.

The application relies on 2 main JSON files in your selected folder:

tasks-input.json

Defines your baseline task list, schedule times, pillar categories, and activity descriptions.

tasks-tracker.json

Stores checked task completion state per date (e.g., {"2026-10-16": {"checkedTasks": ["task1"]}}). Automatically updated whenever you check a task.

3. File System Access API & Privacy Security

This web app utilizes the modern browser File System Access API combined with IndexedDB handle caching:

100% Private & Local

Your data never leaves your device. No cloud server, remote database, or third-party analytics are used.

Explicit Permission Prompt

Browsers enforce strict security prompts. The app can only read and write to the single folder you explicitly choose.

4. Data Loss & File Manipulation Warning

Please handle your local JSON files with care!

  • Deleting or Renaming Files: If tasks-tracker.json is deleted or renamed, your historical records will be permanently lost unless restored from a backup.
  • Manual Edits / External Programs: If another application or text editor modifies tasks-tracker.json or tasks-input.json with invalid JSON formatting, application read errors may occur.
  • Backup Recommendation: Regularly back up your local folder directory if keeping long-term historical routine data is critical to you.
