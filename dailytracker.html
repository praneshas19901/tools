App Instructions & File Access Guide

How to Use the App

1. Connect or select a local working folder using the Connect Data Folder button.

2. Complete daily schedule items using the checkboxes on the Today tab.

3. Use the date selector to navigate past days or jump back to present execution schedules.

4. Check overall performance, completion averages, and uncompleted items under the History & Missed tab.

5. Manage tasks dynamically in the Manage Tasks tab to add, edit, delete, or reorder your schedule.

Folder Connection & JSON Files

When you select a local folder, if the required JSON files don't already exist, the app automatically creates default files in that folder for you:

  • tasks-input.json: Contains standard daily routine activities, times, and categories.
  • tasks-tracker.json: Stores historical task completions keyed by date.

File System API & Security Model

This web application utilizes the modern browser File System Access API. Here is what you should know regarding security:

  • 100% Local & Offline: All readings and writes are done strictly on your device. No data is transmitted to external servers.
  • Sandboxed Permissions: The web browser requires explicit user permission before granting access to read or write in any directory.
  • Session Caching: Directory handles are securely retained in local IndexedDB to allow seamless access when returning to the app without picking the path again.

Caution: External Modifications & Data Loss

Since data resides in standard JSON files on your hard drive:

  • If tasks-tracker.json or tasks-input.json is deleted, overwritten, or moved manually or by another application, permanent data loss can occur.
  • Invalid syntax introduced when manually editing JSON files outside this app will prevent the tracker from loading correctly.
