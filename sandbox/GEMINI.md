# Gemini CLI Sandbox Instructions

This directory serves as an isolated sandbox environment for testing Gemini CLI commands, agent workflows, code refactoring, and automated testing.

## Sandbox Guidelines
1. **Safety First**: All edits made here are contained within the `sandbox/` directory.
2. **Experimentation**: Feel free to test prompt engineering, file modifications, subagent delegation, and tool execution here.
3. **Verification**: Always run the associated test suite (`npm test` inside `sandbox/sample-app`) after making changes.
