User Guide & Instructions

1. Connecting to local inputs-and-data.json

This app reads & writes directly to your computer using the modern File System Access API. Click "Connect JSON File" in the top navigation to create or choose your local inputs-and-data.json file.

2. Automatic Next-Visit Reconnection

Your local file handle is saved securely inside your browser's IndexedDB. When you reopen the page later, the app will remember your file and ask for a quick 1-click permission confirmation to load automatically!

3. Swim Lanes & Task Reordering

Drag task cards between any of the 4 priority columns (High, Medium, Low, De-prioritized). To reorder tasks within a column, drag them vertically or use the Up/Down arrow buttons on each card.

4. Minimizing Cards

Click the Minimize icon in any task card header to collapse it into a compact row showing only the checkbox, title, and deadline date badge.

5. Completion & History Archive

Checking off a task checkbox or sliding progress to 100% automatically hides it from the main board and moves it to the Completed History. Click "Completed" in the top navbar anytime to review or restore archived tasks.
