How to Use Kanban Board Task Tracker

4 Priority Lanes

Tasks are organized into 4 distinct lanes: High Priority, Medium Priority, Low Priority, and De-prioritized.

Drag & Drop or Quick Move

Drag any task card to move it between lanes or reorder tasks within a lane. You can also use the drop-down menu on each card to transfer it instantly.

Automatic Reconnect to Local JSON File

This app uses IndexedDB to store your local file handle. On every visit, the board automatically attempts to reconnect to your inputs-and-data.json file on disk!
