Complete User Guide: Kanban Task Tracker

1. Connecting Local JSON (inputs-and-data.json)

This web app uses the modern File System Access API to write updates directly to your hard drive without server uploads.

  • Click "Create inputs-and-data.json" to initialize a new dataset on your machine.
  • Or click "Connect JSON" to select an existing inputs-and-data.json file.
  • If your browser doesn't support direct file writing, fallback Download/Upload buttons are available.

2. Auto-Reconnect Feature

Your local file handle is saved securely in your browser's IndexedDB storage. Whenever you revisit or refresh this page, the app will automatically request permission and re-bind to inputs-and-data.json instantly.

3. Swimming Tasks & Priority Lanes

Tasks swim inside 4 color-coded currents:

Lane 1: High Priority (Red) Lane 2: Medium Priority (Amber) Lane 3: Low Priority (Green) Lane 4: De-prioritized (Indigo)

4. Moving, Reordering & Editing

  • Drag & Drop: Grab any task card to move it between lanes or reorder cards vertically.
  • Quick Move: Click the Move ▾ button on any task card to transfer it with one click.
  • Task Details: Double click or hit the edit pencil icon to modify progress percentages, set deadlines, or append notes.
