Help, Micronutrients & File Persistence Guide

🧪1. Full Micronutrients & RDA Limits

Tracks Sodium, Potassium, Calcium, Iron, and Vitamin C in real-time as you log meals. Visual progress bars highlight when you approach or exceed daily limits (e.g. low-sodium framework).

📁2. Reconnecting food-database.json After Refresh

Browser security prevents file handle pointers from surviving page reloads automatically. However, clicking "Reconnect DB File" checks your cached IndexedDB handle reference so you can instantly re-verify disk access with a single click without searching your file picker.
