Help, Privacy & Security Guide

🚀1. How to Use NutriTrack Pro

NutriTrack Pro tracks your daily calorie and macronutrient intake using a local JSON database file or Supabase cloud sync. Click "Add Food / Search" to search across your local database or query Open Food Facts.

📁2. Managing food-database.json (Local DB)

  • First-Time Initialization: Click the sparkle icon (✨) to generate and download the default database pre-populated with 18 well-known food items.
  • Live File Sync: Click "Connect DB File" to link your local disk file. Modifications made in the app persist directly to disk.
  • API to Local DB: When searching external APIs like Open Food Facts, click "+ Save to DB" on any result to permanently store it in your local JSON database.

🔒3. Privacy & File System Access API Security

Your privacy is maintained through a local-first architecture:

  • Sandboxed Browser Permissions: The app utilizes the W3C File System Access API. Your browser strictly isolates file access—the app can only read or write to the specific food-database.json file that you explicitly select.
