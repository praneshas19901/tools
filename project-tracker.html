How to Use Project Tracker

📁 Local Storage & File Access API

This app reads and writes directly to a .json file on your local machine using the native File System Access API.

  • First Time Setup: Click 📁 Create New File to initialize a local JSON file (e.g., projects.json).
  • Revisiting Users: The browser automatically reconnects to your last-used handle. If prompted, confirm write access permissions.
  • Manual Reconnect: Click 📂 Connect Existing File to select your previously saved JSON file.

🚩 Milestones & Weighted Progress

  • Each project's overall progress is calculated from weighted milestones.
  • Assign percentage weights to milestones (the sum of all milestone weights across a project should target 100%).
  • Completing tasks inside a milestone dynamically updates that milestone's completion percentage and recalculates the total project progress.

📝 Timestamped Notes

  • You can attach notes at both the Milestone level and Task level.
  • Notes are automatically prefixed with the exact local timestamp when posted.
