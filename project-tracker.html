How to Use Project Tracker

📊 Interactive Gantt Chart View

  • Click the 📊 Gantt Chart button on any project card to view an interactive visual timeline.
  • Direct Board Navigation: Click any project, milestone, or task bar inside the Gantt chart to close the timeline, scroll straight to that item on the main board, and open its edit dialog instantly.

📝 3-Level Editable Note System

  • Project Level Notes: Keep macro-level status logs, strategy notes, or team updates.
  • Milestone Level Notes: Track phase deliverables, blockers, or milestone reviews.
  • Task Level Notes: Store granular developer notes, links, or technical details.
  • Edit & Delete: Click the edit (✏️) icon to update any note or the trash (🗑️) icon to remove it.

↕️ Minimizing Project Cards

  • Click Minimize / Expand on any card to collapse its details.

🏆 Completed Projects Archive

  • Projects reaching 100% completion move into the Completed Projects view automatically.
