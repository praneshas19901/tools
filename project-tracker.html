How to Use Project Tracker

📁 Local Storage & File Access API

This app reads and writes directly to a .json file on your local machine using the native File System Access API.

  • First Time Setup: Click 📁 Create New File to initialize a local JSON file.
  • Revisiting Users: The browser automatically reconnects to your last-used file handle.

💰 Budget Management (in Lakhs ₹)

  • Project Level: Enter total budget in Lakhs. Shows allocated vs. remaining budget based on milestone budgets.
  • Milestone Level: Milestone budgets are distributed from the project budget and cannot exceed remaining limits.
  • Task Level: Allocate specific budgets for individual tasks within milestones.

⏳ Time & Deadlines

  • Projects display real-time days remaining from today's date based on the project deadline.
  • Milestones and tasks have dedicated start and deadline dates distributed across the project schedule.

🚩 Milestones & Weighted Progress

  • Assign percentage weights to milestones (total across project must sum to 100%).
  • Completing tasks updates milestone completion and total project progress.

📝 Timestamped Notes

  • Attach timestamped notes at both Milestone and Task levels.
